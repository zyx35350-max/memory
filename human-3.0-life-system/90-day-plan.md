# 90-Day Evolution Plan

## Goal

Turn the current career direction into a real marketable profile while building a sustainable execution system.

Primary direction:

**AI product / AI application / AI solution-oriented work**

The first job does not need to be a perfect match. It needs to create a strong bridge toward the long-term direction.

# Days 1-30 — Enter the market

Objective:

**From thinking about the direction -> showing evidence of the direction.**

Deliverables:
1. Finish the primary resume.
2. Build one strong portfolio case.
3. Start targeted applications.
4. Keep English output and professional skill development, but do not let them consume the entire day.
5. Establish a stable sleep boundary.

### Portfolio case

Use the AI job-search assistant or another suitable AI application project.

Document:

**Problem -> user -> evidence -> hypothesis -> solution -> prototype -> feedback -> changes -> limitation -> next step.**

The case should demonstrate problem solving, not just tool usage.

### Month 1 success test

There must be visible artifacts and real applications/interactions with the market.

# Days 31-60 — Increase real feedback

Objective:

**Replace self-evaluation with market evaluation.**

Actions:
- Continue targeted applications.
- Conduct interviews and/or product/user conversations.
- Ask for portfolio feedback.
- Compare target job descriptions and identify recurring skill requirements.
- Update the portfolio based on real feedback.

Weekly output should include at least one externally testable result:
- application;
- interview;
- product test;
- user conversation;
- portfolio revision;
- published content;
- industry conversation.

# Days 61-90 — Convert capability into opportunity

Objective:

**Show that the skill can create value.**

Possible evidence:
- stronger interview performance;
- concrete project result;
- user validation;
- improved portfolio;
- first relevant offer;
- freelance/part-time opportunity;
- clearer specialization based on repeated market feedback.

The question changes from:

"What job do I want?"

to:

**"What problem can I reliably solve that the market values?"**

# Daily architecture

Do not copy a giant schedule.

Use a few blocks:

1. **Main career work** — applications, product project, portfolio, interview preparation.
2. **Skill compounding** — English + one high-value professional skill.
3. **Body** — exercise + sleep preparation.
4. **Optional creation** — self-media/content after the day's core work is protected.

# 90-day metrics

| Metric | Weekly check |
|---|---|
| Market outputs | applications / interviews / external feedback |
| Product outputs | concrete project progress |
| Learning | hours converted into usable artifacts |
| Creation | posts / notes / published experiments |
| Body | sleep + exercise consistency |
| Focus | times new information displaced the main task |

Do not optimize the dashboard. Use it to notice patterns.

# Success definition

A successful 90 days means:

**more evidence, more capability, more market feedback, and a more stable daily rhythm.**

It does not require a perfect career answer.
